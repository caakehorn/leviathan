◂ THE WIKI SINGULARITY

The corpus only knows what was already written down somewhere — texts, posts, exports. The formative things that were only ever said out loud are invisible to it. This is where those get in. Type a fact or a story, it joins the ongoing article below, and when you signal the system the whole queue gets analysed, linked, speculated on, and written into the wiki as readable pages.

THE INGEST BRIEF is the primary export: one markdown file carrying every entry and the complete instructions any capable LLM needs to parse them, write them into wiki-brain correctly, and open a pull request — including the rules, the frontmatter spec, the typed-edge vocabulary, and three routes to a PR (terminal, browser-only, or API). It exists so the wiki keeps growing when Claude is unavailable. Paste it into whatever model you can reach.
